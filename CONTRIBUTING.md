# Contributing to NoxGuard

Thank you for your interest in contributing to **NoxGuard**.

NoxGuard is an open-source reference implementation that demonstrates how existing Solidity smart contracts can be extended with **Confidential Business Lifecycle Management** using **iExec Nox**.

We welcome contributions from developers, researchers, architects, and the Web3 community who are interested in programmable privacy and confidential smart contracts.

---

# Code of Conduct

Please be respectful, constructive, and collaborative.

We value:

- Professional communication
- Technical discussions
- Open collaboration
- Respectful code reviews
- Well-documented contributions

---

# Ways to Contribute

Contributions may include:

- Solidity smart contract improvements
- iExec Nox integrations
- Architecture enhancements
- Security reviews
- Documentation improvements
- UI/UX enhancements
- Testing and bug fixes
- Performance optimizations
- Example integrations with existing Solidity protocols

---

# Development Workflow

1. Fork the repository.
2. Create a feature branch.

```bash
git checkout -b feature/my-feature
```

3. Make your changes.
4. Commit using clear commit messages.

Example:

```text
feat: add confidential policy verification
```

5. Push your branch.

```bash
git push origin feature/my-feature
```

6. Open a Pull Request.

---

# Pull Request Guidelines

Please ensure:

- Code is well documented.
- Functions are clearly named.
- Existing architecture is preserved.
- New features include documentation.
- Changes align with the NoxGuard design philosophy.

---

# Project Principles

NoxGuard follows several core principles.

## Preserve Existing Protocols

NoxGuard extends existing Solidity applications rather than replacing them.

---

## Separation of Responsibilities

- Existing Protocol → Business Operations
- NoxGuard → Confidential Business Lifecycle Management
- iExec Nox → Confidential Computation
- Ethereum → Settlement

---

## Programmable Privacy

Confidential Business Policies should remain confidential while preserving protocol composability.

---

## Developer First

NoxGuard is designed as a reusable programming model for Solidity developers.

Contributions should improve developer experience wherever possible.
